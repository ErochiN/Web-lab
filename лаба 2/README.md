Данный проект является продолжением Лабораторной работы №1.

## Выполненные требования

### 4. Форматирование текста и фон
- Использованы теги `<h1>`–`<h4>` для заголовков разного уровня.
- Применены атрибуты `face`, `size`, `color` (через CSS-стили и устаревшие теги согласно методичке).
- Использованы теги `<i>` (курсив).
- В `b.html` установлен цвет фона: `style="background-color: #f0f8ff;"`.

### 5. Изображения (выравнивание)
- В `images.html` три изображения расположены по левому краю, центру и правому краю.
- Каждое изображение является гиперссылкой на самого себя и открывается в новом окне (`target="_blank"`).

### 6. Гиперссылка-изображение
- В `image.html` изображение обёрнуто в тег `<a>` с `target="_blank"`, что открывает другое изображение в новом окне.

### 7. Фон картинкой + параграф
- В `backgroundimage.html` фон задан через атрибут `background` у `<body>`.
- Добавлен тег `<p>` с текстом.

### 8. Вложенные списки
- В `spisock.html` реализован:
  - нумерованный список `<ol>` (Музыка, ИЗО, Спорт);
  - вложенный маркированный список `<ul>` внутри каждого пункта;
  - отдельный список определений `<dl>` с терминами и их описаниями.
