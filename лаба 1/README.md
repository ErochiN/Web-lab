# Лабораторная работа: Основы HTML

## Описание проекта
Данный проект представляет собой набор HTML-страниц, созданных в рамках выполнения лабораторной работы. 
Цель работы: изучение базовых тегов HTML, создание навигации между страницами, использование специальных символов и мета-тегов.

## Структура проекта
Проект состоит из следующих файлов:

*   **a.html** — Главная страница с описанием семьи.
*   **b.html** — Страница с описанием домашних животных. Особенность: страница автоматически обновляется каждые 5 секунд (мета-тег `refresh`).
*   **c.html** — Страница с описанием увлечений и хобби.
*   **speshia.html** — Страница, демонстрирующая использование специальных символов HTML (мнемоник).

## Реализованные требования
1.  **Навигация:** На всех страницах присутствует навигационная панель (`<nav>`), позволяющая переходить между разделами.
2.  **Ссылки:** Реализованы прямые и обратные ссылки между страницами `a.html` и `b.html`.
3.  **Мета-теги:** На странице `b.html` установлено автообновление каждые 5 секунд.
4.  **Контент:** Использованы таблицы для структурирования данных о семье, животных и хобби.
5.  **Спецсимволы:** Показано использование символов `<`, `>`, `&`, `"`, `'`, ` ` (неразрывный пробел).

## Как запустить
1.  Скачайте все файлы проекта в одну папку.
2.  Откройте любой из файлов (например, `a.html`) в любом современном веб-браузере (Chrome, Firefox, Edge).
3.  Используйте верхнее меню для навигации по страницам.

## Технологии
